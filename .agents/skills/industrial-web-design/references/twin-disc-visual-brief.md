# Twin Disc website visual brief

This reference is project-specific guidance for the current Astro MVP.

## Audience
Maintenance managers, equipment dealers, rebuilders, service shops, fleet operators, and technical buyers who may know a part number, machine model, OEM number, or clutch/PTO family.

## Primary jobs
1. Search a known part number quickly.
2. Establish confidence that the seller understands technical fit.
3. Submit enough equipment information for compatibility verification.
4. Request a quote without creating an account.

## Desired visual character
Modern industrial catalogue: precise, robust, technical, calm, and credible. Think high-quality engineered-equipment documentation translated into a modern web storefront—not an enterprise SaaS landing page.

## Suggested starting tokens
These are starting points, not fixed requirements.

- Ink: #111820
- Steel: #4E5B66
- Paper: #F4F5F2
- White: #FFFFFF
- Signal blue: #175D8D
- Safety accent: #D88A1C

Use Signal blue for primary actions and links. Safety accent is for warnings/status only, not decoration.

## Layout cues
- Desktop max content width around 1180–1280px.
- Header can be compact and utilitarian.
- Hero should emphasize searchable inventory/part identification, not a generic value proposition.
- Consider a large search field as the hero's primary object.
- Catalogue results can be row-based or compact cards; emphasize part number, family, model family, and quote action.
- Product pages should resemble technical product sheets: identity at top, key metadata in a structured block, compatibility evidence and RFQ path below.
- RFQ form should feel like a technical intake form, with optional fields grouped by what the buyer may have available.

## Avoid
- Fake reviews, fake customer logos, fake inventory counts.
- Unsupported statements like "fits hundreds of machines".
- Stock photography that implies a relationship or installation not actually evidenced.
- Presenting the site as an official Twin Disc property.
