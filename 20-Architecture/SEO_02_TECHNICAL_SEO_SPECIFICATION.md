# SEO-02 — Technical SEO Specification for SEO-03
**Design-only handoff. Do not mistake source audit for working production.** SEO-01 verified Astro static preview website source in 50-Code/site on experimental feature branches of SAME twin-disc repository; main and SEO research branch are separate from website source. Inspect selected website feature branch in SEO-03; do not silently alter another redesign experiment. Astro preview uses trailingSlash=never; its /products/[sku] mixes model and SKU; local RFQ merely drafts a message; sitemap and robots observed in source, not live. Configured twd.andel-vps.space is NOT verified canonical domain. Vercel production-target deployment observed canceled.

**Implementation contract:** Astro pre-rendered meaningful body and links for approved pages; central approved-origin canonical, consistent trailing slash and redirects; title/meta/H1/OG and source review date; product ID and OEM alias lookup with exact/approved vs family vs unknown/HOLD states; no duplicate slug/intent. Only Published, approval-valid 200 self-canonical substantive pages in XML sitemap. Server-rendered metadata and JSON-LD must consume filtered public claims.

**Schema.org:** BreadcrumbList mirrors visible breadcrumb; Product on exact approved SKU with actual product identity but no unproven Offer, inventory, ratings or price. CollectionPage for categories, TechArticle or Article for safe guides; Organization/LocalBusiness only with verified independent seller entity and customer-facing location. No fake FAQ rich-results eligibility or ghost reviews. All markup matches visible approved copy and applicable source scope.

**Components required for SEO-03:** HeaderNav, Breadcrumbs, CategoryGrid, ModelFamilyIndex, ExactPartIdentity, TechnicalSpecsTable (units, variant, revision), VerifiedCrossReference (Yes/Exact only), ScopeLabel (Family-only context), EquipmentUsageCard (Yes/Exact-equipment), CitationFootnotes, RelatedContent, ReviewStamp and RFQCallout. Filter raw research before components; do not rely on editorial copy hiding forbidden records. Empty state shows model identification, not guessed alternatives.

**Search:** normalize case, hyphen and internal -TWD suffix without collapsing meaningful part characters; use exact approved OEM aliases, never Review as an equivalent. Category/model/SKU differentiated results; unknown model leads to manual inquiry. HOLD has no purchase, order, Offer or confirmed replacement. Site quote button only labelled as submitted after SEO-04 server acknowledgement. Dynamic RFQ, backend storage/privacy and staff notification are SEO-04, NOT this design phase.

**Migration:** first crawl verified deployed routes and inspect HTTP redirects; map /products/{sku}/ to /parts/{part}/ only for confirmed matching approved page. Do not blindly redirect /products/{family} or held old assemblies. Run canonical/robots/sitemap/schema tests, accessibility, mobile keyboard, rendered vs source HTML, link checker, 301 single-hop, Lighthouse lab data, and GSC/CrUX only if available. Stage blocked from indexing; no production changes until approved. Document tests as real only after execution.

**Dependencies:** owner identity and reseller authorization, RFQ recipient/team and privacy, actual fulfilled regions/services, current source revisions, technical approver, image rights, source-proof per claim, final hostname, appropriate website source branch. These remain unresolved even if schemas validate.
