# SEO-01 — Keyword Mapping Methodology

Research date 2026-10-19. 137 candidate phrases mapped to 43 proposed canonical URLs. **These are grounded topic/relevance candidates, not verified keyword demand.** Search volume, ranking and competition data have not been measured; see explicit NA fields in CSV. A source URL supports the product/topic association, NOT a claim that the keyword ranks.

Priority weighting is qualitative: commercial intent first, existing Launch-20 fit second, public Phase 4 evidence readiness third, then buyer value, Ontario context, opportunity, ease and RFQ value. P0 = high-intent and draftable; P1 = strong topic but technical/commercial approval; P2 = research/technical depth; REVIEW/HOLD/BLOCKED = not eligible for exact public promotion.

Canonical separation: category page owns general parts search; model hub owns family keywords; exact SKU page owns genuine part-number and **verified** OEM aliases; guides own symptoms and identification; dedicated solution page owns ambiguous parts sourcing. Local pages require unique operational geographic value. The proposed /parts/{sku}/ paths are SEO-02 architecture suggestions and do **not** describe current deployed URLs; feature preview currently uses /products/[sku]. Map migration with redirects before shipping.
