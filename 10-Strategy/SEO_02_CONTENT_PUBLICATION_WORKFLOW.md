# SEO-02 — Controlled Editorial Workflow
**Future implementation specification, not current automated publishing.**
Research (unique intent, owner, audience) → Structured Evidence (Phase4 relationship, versioned source, applicability, known contradictions) → AI Draft (supported claims only + explicit missing evidence) → Automated Validation (syntax, facts, duplicate intent, sensitive-data scan and all asserted fields with sources) → Technical Review (qualified human signs variant/fit/safety) → Commercial/Legal Review (owner verifies legitimate seller rights, local services, asset rights, privacy, RFQ response) → Approved (immutable snapshot, current reviews and next review date) → Published (separate deployed release with QA) → Periodic Revalidation.

**Exit criteria:** Research needs named editor and page/intent; Evidence needs claim IDs and revision mapping; Draft needs source citations; Validation needs no blocking findings; Technical Review needs named reviewer/date/claim hashes; Commercial needs seller/rights/capability signatures; Approved needs both approvals and appropriate freshness; Published needs production release/crawl records; Revalidation recertifies after any content/evidence change. Failure goes to Blocked/Hold/NeedsRevalidation. AI output alone can never set Approved. HOLD SKU path stays internal/manual only.

**Approval record:** page ID, version/content hash, source row IDs, source revisions, evidence snapshot hash, technicalReviewerId, technicalReviewedAt, commercialReviewerId, commercialReviewedAt, rightsApprovalId, claimRegisterDecisions, date of next check, releaseCommit, blockers, change log. Invalidate all approvals on material change, new supersession, contradicted fit, revised manual, broken sole source, liability or copyright challenge. Human reviewer identity is authenticated by future implementation, never merely supplied as AI text.

**Release order:** SEO-02 schemas/documented fixtures → SEO-03 site renderer/evidence guardrails/crawl → SEO-04 real staffed RFQ and privacy → SEO-05 approved commercial pages → later marine/regional content. This file does not authorize publishing.
