# SEO-02 — Reusable Page Templates and Worked Examples

**Design only.** Every template inherits ID, title, meta, canonical, unique primary intent, author/editor, source IDs, source revision, last updated, technical reviewer, approval, next review, unique sections and related links. The examples below identify real research topics; no numeric performance, interchange, available shop or stock is invented. The canonical URL uses the still-unapproved origin.

**Intent matrix:** category=generic purchasing; model-hub=family identification; SKU=exact part/OEM; identification=unknown model; comparison=model differences; troubleshooting=problem symptom; maintenance=service planning; repair-vs-replace=decision; application=equipment category; location=region with verified fulfilment; rfq-solution=uncertain part sourcing. One indexable intent owner per query; do not duplicate category/model/SKU snippets.

**Migrations:** keep Phase4 and Phase5 CSVs intact; adapter maps public fields 1:1 (SourceSKU to sourceSku, SourceURL to sourceUrl) and persists original sourceRowId.
